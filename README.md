## 🌟 Le concept

Qard révolutionne le networking professionnel en remplaçant les cartes de visite papier par une expérience digitale premium et interactive. Plus qu'une simple carte, Qard est votre identité professionnelle connectée.

### ✨ Fini les cartes papier perdues
Créez votre carte de visite digitale personnalisée et partagez-la instantanément via NFC, QR code ou lien. Vos contacts la reçoivent directement sur leur téléphone, sans avoir besoin d'installer une application.

### 🎯 Une solution pour tous les professionnels

- **Commerciaux** qui collectent des leads en permanence  
- **Entrepreneurs** qui networkent dans les événements

## 🚀 Comment ça marche

### 1. **Créez votre profil**
Renseignez vos informations, ajoutez votre photo, personnalisez les couleurs et le design de votre carte selon votre image de marque.

### 2. **Partagez en 1 seconde**
- **NFC** : Approchez votre téléphone de celui de votre contact
- **QR Code** : Laissez scanner votre code personnel
- **Lien** : Envoyez votre carte par message ou email
- **Kiosque** : Présentez votre carte sur une tablette ou un écran lors d'événements pour permettre à plusieurs personnes de la scanner facilement

### 3. **Vos contacts reçoivent tout**
Ils accèdent à votre carte depuis leur navigateur, peuvent vous contacter directement, prendre rendez-vous ou même vous payer - tout en un clic.
